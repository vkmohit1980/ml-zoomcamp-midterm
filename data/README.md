# Dataset attribution

Singh, A. & Chaudhari, S. (2018). Room Occupancy Estimation [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5P605

License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The bundled CSV is the unchanged UCI source. Its SHA-256 is recorded and enforced by `data_source.py`.

The target is the manually observed integer room occupancy count. Light readings are in lux, CO₂ in ppm, temperature in Celsius, sound sensor output in volts, and PIR readings indicate motion. Date and time are used only to partition the data.
